Das Atelier

Entworfen in Amsterdam, verwurzelt in Marokko.

من أمستردام، بجذور مغربية

Balacona Studio ist eine kleine Gruppe von Künstlern, die arabische Kalligraphie und Familien-Printables mit Sorgfalt herstellt: zweisprachig von Grund auf, zweimal geprüft und von Hand personalisiert.

Das Atelier kennenlernen →
Zweisprachig von Grund auf. Arabisch zuerst, mit Englisch, Niederländisch, Französisch oder Deutsch daneben.
Zweimal geprüft. Daten gegen den Hidschri-Kalender, Texte vor der Veröffentlichung Korrektur gelesen.
Von Künstlern gemacht. Eine kleine Gruppe von Künstlern, keine Druckfabrik.
